# Arquivos arquivados

Esta pasta guarda materiais que não participam da execução atual do app nem do painel.

- `publicar/index.html`: cópia antiga de publicação, diferente do `index.html` atual da raiz. Para novas publicações, use o arquivo da raiz.
- `Modelo/Template_RDC (1).html` e `Modelo/PROMPT_UI_UX_RDC (1).md`: referências antigas de prototipação, sem uso pelo código atual. `Modelo/DESIGN.md` continua no local original porque ainda é citado pelo app.
- `agents/skills-antigas`: versões antigas ou duplicadas das skills. As versões ativas estão em `.agents/skills`.
- `agents/interface-design-antigo`: notas do sistema visual anterior, sem referências ativas no projeto.

Os arquivos foram movidos sem alteração de conteúdo para permitir recuperação, se necessário.
