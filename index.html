Edição do administrador

“Editar dados” (contrato, data, OM, PTS, bloqueio) altera este RDC no lugar. “Editar tudo” (atividades, fotos, impactos) grava uma nova versão no lugar desta, mantendo a situação (validado continua validado).

Remove o RDC, as versões anteriores e as fotos. Não pode ser desfeito.

Editar dados do RDC

Altera este RDC no lugar (mesmo código e situação). Fica registrado quem alterou e o valor anterior. Mudar a data move junto os horários.

Consulta somente leitura. Um RDC emitido só pode ser corrigido quando o administrador libera a revisão.

Acesso do administrador

Necessário para as configurações do banco de dados e para validar RDC.

Área do administrador. O padrão vem do bloco CONFIG do index.html. O administrador pode definir o modo para todos os aparelhos; a URL/chave do Supabase continuam as do arquivo.

Diagnóstico

Cria o que falta e, nas listas existentes, acrescenta colunas e opções novas (nada é apagado). Exige permissão de proprietário do site (escopo Sites.Manage.All).

Sincronização SharePoint

Os RDC ficam no Supabase e são copiados automaticamente para as listas e a biblioteca do SharePoint (validação, revisão, cancelamento e exclusão também).
