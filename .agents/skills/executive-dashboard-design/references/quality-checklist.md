# Checklist de aceite

## Dados e indicadores
- [ ] Fonte, data de atualização e período informados.
- [ ] Fórmulas, unidades, metas e denominadores corretos.
- [ ] Dados faltantes não foram convertidos indevidamente em zero.
- [ ] Totais, subtotais e agregações reconciliados.

## Gráficos
- [ ] Tipo de gráfico responde à pergunta analítica.
- [ ] Eixos e unidades claros; barras com zero.
- [ ] Eixos mais visíveis que linhas de grade finas.
- [ ] Área de plotagem suavemente cinza, não branco puro por padrão.
- [ ] Sem sobreposição de textos, rótulos, tooltip ou legendas.
- [ ] Cores consistentes e compreensíveis sem depender só de cor.

## Interface e UX
- [ ] Hierarquia resumo → desempenho → desvios → ações.
- [ ] Espaçamentos, alinhamentos e fontes consistentes.
- [ ] Botões retangulares com raio sutil de 2–4 px.
- [ ] Layout funcional em desktop, tablet e mobile.
- [ ] Estados loading, erro, vazio e sem permissão tratados.
- [ ] Foco visível, navegação por teclado e contraste adequado.

## Implementação
- [ ] Gráficos redimensionam corretamente sem vazamento de listeners.
- [ ] Formatação pt-BR consistente.
- [ ] Nenhuma credencial secreta no front-end.
- [ ] Não há erros no console nem componentes cortados.
